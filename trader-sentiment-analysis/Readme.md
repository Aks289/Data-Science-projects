# Bitcoin Market Sentiment vs Trader Performance Analysis

## Project Overview

This project analyzes the relationship between Bitcoin market sentiment and trader performance using:

1. Bitcoin Fear & Greed Index
2. Historical Hyperliquid Trader Data

The objective is to uncover behavioral trading patterns, sentiment-driven profitability trends, and insights that can support AI-driven trading systems.

---

## Datasets Used

### 1. Fear & Greed Index Dataset
- Date
- Classification (Fear, Greed, Extreme Fear, Extreme Greed)
- Value

### 2. Hyperliquid Historical Trader Data
- Account
- Coin
- Execution Price
- Size USD
- Side
- Closed PnL
- Fee
- Timestamp
- Direction
- etc.

## Project Workflow

1. Data Cleaning

7. Correlation Analysis
8. Behavioral Finance Insights

---

## Key Findings

### 1. Extreme Greed produced the highest profitability and win rates.
- Traders performed best during bullish market conditions.

### 2. Fear conditions generated the highest trading activity.
- Traders became more aggressive during volatile periods.

### 3. Fear markets showed the largest trade sizes and highest trading fees.
- Suggesting emotionally driven and volatility-focused participation.

### 4. Certain assets displayed strong sentiment sensitivity.
- Coin-specific behavior varied significantly across sentiment regimes.

### 5. Trading performance exhibited weak linear correlations.
- Indicating nonlinear market dynamics better suited for AI/ML modeling.
